### 1. 원작 규칙 대조 (rulespal 기본판·로얄판 규칙서, 로얄 영문 규칙서, 위키백과, 상품 구성표)

  “왕” 이라는 말, 왕을 펼치면 벌칙 더미 윗장(또 왕이면 반복)·새 윗장 공개, 손에서 값으로 낸 왕도 벌칙, 특수 카드 떠안으면 손으로 + 맞는 1장/아무 2장, 4장(2인 5장)·빈손 패배 → **모두 맞음**
- **고침: 기본판 2인** — 원작은 10장을 보지 않고 빼고 나누고, 넘기기 없이, 같은 생물 **5장**이면 패배. 4장이던 것을 5장으로, 10장 빼기 추가, 화면 위 알림줄에 표시
- **고침: 검은 카드 그림** — 원작은 “아무것도 그려지지 않은 카드”. 나방 무늬를 걷어 빈 카드로
- **정함: 벌칙 더미에서 특수 카드가 나온 경우**(원작에 없음) — 그냥 손에 넣으면 벌칙이 이득이 되므로 떠안았을 때와 똑같이 값을 치른다. 규칙 화면에 “원작에 없는 경우라 이렇게 정했다” 고 적음
